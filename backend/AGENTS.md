# Инструкции AGENTS

Этот файл содержит инструкции для контрибьюторов репозитория *backend-mono-repo*.

## Общие правила

1. **Документация пишется на русском языке.**
2. **Тесты обязательны.** При изменении кода запускайте тесты для соответствующего сервиса.
   - Go‑сервисы: `go test ./...`
   - Node.js‑сервисы: `npm test`
3. **Линтинг.** Если в сервисе присутствуют линтеры (например, `golangci-lint` или `npm run lint`), необходимо убедиться, что они проходят успешно.
4. **Коммиты на английском.** Используйте краткие описательные сообщения в повелительном наклонении: `Add feature`, `Fix bug` и т.д.
5. **Описание PR.** В теле pull request кратко опишите внесённые изменения и приложите результаты тестов.
6. Взаимодействия с пользователям - ответы и комментарии должны быть на русском языке 
Эти рекомендации действуют для всего репозитория, если нет более конкретных инструкций в вложенных `AGENTS.md`.

### Работа с gRPC и proto
Разрешены gRPC‑вызовы между сервисами через их публичные API. При этом **запрещены прямые импорты чужих proto‑файлов как модулей** — каждый сервис хранит копию нужных `.proto` в своём репозитории.
Требования для работы с сервисом описаны в: backend/documentations/requirements/architecture-principles.md
