# Бизнес-потоки

1. **UploadOriginal**
   - gRPC-клиент передает org_slug, project_slug, document_id, расширение и байты файла.
   - Service генерирует ключ по шаблону и пишет объект в приватный бакет `knowledge-docx`.
   - Возвращается bucket/key для последующей записи статуса документом.

2. **UploadMarkdown**
   - После конвертации docling-трансформером вызывается загрузка Markdown.
   - Файл пишется в бакет `knowledge-md` с тем же ключом (расширение `.md`).

3. **GetObject**
   - Клиент запрашивает bucket + object_key, сервис проверяет доступность бакета и отдает содержимое.

Все операции логируются через gRPC-обвязку (не реализована в данном скелете) и используют приватные бакеты MinIO.
