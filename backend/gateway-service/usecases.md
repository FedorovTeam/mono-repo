# usecases

## Загрузка нового знания
1. Пользователь выбирает DOCX и заполняет путь в GitHub.
2. Отправляет `uploadKnowledgeDocument` с базовой авторизацией по `X-API-Key`.
3. Получает ID документа и статус `Uploaded`.
4. Отслеживает прогресс через `knowledgeDocument`.

## Повторная обработка после ошибки
1. Пользователь получает статус `Failed`.
2. Вызывает `retryProcessing` с указанным ID.
3. workflow перезапускается, статусы обновляются в document-service.
