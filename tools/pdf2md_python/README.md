# Il Tumen PDF → Markdown (с галочками)

Небольшой конвертер, который извлекает таблицу голосования из PDF-протоколов «Ил Тумэн» и сохраняет её в `.md` так, чтобы **галочки (✓) попадали в правильные ячейки**.

В этих PDF галочки являются **векторными объектами** (не текст и не растровая картинка), поэтому OCR не нужен: мы читаем векторные рисунки страницы и раскладываем их по клеткам таблицы.

## Установка

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

### Один файл

```bash
python -m iltumen_pdf2md "./file.pdf" -o "./out.md"
```

### Папка с PDF

```bash
python -m iltumen_pdf2md "./pdfs" --out-dir "./out"
```

## Формат вывода

- В начале файла идёт текст, который расположен *выше таблицы* на первой странице PDF.
- Ниже — Markdown-таблица.
- В колонках голосования стоит символ `✓` в той ячейке, где в PDF проставлена галочка.

## Ограничения

- Код рассчитан на формат PDF-протоколов `iltumen.ru` (светло-серая сетка таблицы и маленькие чёрные галочки).
- Если дизайн/цвета/толщины линий отличаются, поправьте эвристику поиска сетки и галочек в `src/iltumen_pdf2md/parser.py`.
